Questions

Before you start.

What is NIMAH OFC?

NIMAH OFC is the official home of Nimah Dev's projects: the Nimah MD WhatsApp bot and the Nimah API Hub.

What is Nimah MD?

Nimah MD is a WhatsApp bot. You pair it with your number from its website and use its commands in your chats.

Is Nimah MD an official WhatsApp product?

No. Nimah MD is an independent project and is not affiliated with or endorsed by WhatsApp or Meta.

How do I pair Nimah MD?

Open the Nimah MD site, follow the pairing screen and connect your WhatsApp number. The steps are shown on the page.

Is the site online right now?

The status tags on the project cards check both sites live each time this page loads.

Can I use the API in my own project?

Open the API Hub to see what is available, then call it from your code like the example above.

Something is not working. Who do I tell?

Message Nimah Dev on WhatsApp using the button in the contact section below.
